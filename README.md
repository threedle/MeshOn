# MeshOn Website

This repository contains the source for the MeshOn project website.

The current site is structured as a single-page, MeshUp-style landing page and is now populated with MeshOn paper text, section ordering, and live quantitative tables.

Figure regions are intentionally left as labeled placeholders so final exports can be dropped in manually without changing the page structure.

## BibTeX

Official citation metadata has not been filled in yet. Once the venue or public preprint metadata is finalized, replace the placeholder BibTeX note on the page with the final citation block.
